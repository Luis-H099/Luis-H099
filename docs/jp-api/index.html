JP-API-FINAL

API de gerenciamento de alunos

O que este projeto faz

Uma API REST desenvolvida em C# com ASP.NET Core, SQL Server e Dapper. Ela permite consultar, cadastrar, editar e excluir alunos, além de consultar endereços a partir do CEP.

Esta página é apenas uma demonstração visual. Os botões e exemplos não chamam a API real.
Demonstração estática — não há conexão com SQL Server nem execução dos endpoints.

Rotas disponíveis

GET
/api/aluno/{id}
Busca um aluno pelo ID
POST
/api/aluno/adicionar
Cadastra um aluno
PUT
/api/aluno/{id}
Atualiza os dados de um aluno
DELETE
/api/aluno/{id}
Exclui um aluno
GET
/api/aluno/BuscarCep/{cep}
Consulta endereço pelo CEP

Estrutura do projeto

Controller: recebe as requisições HTTP. Application: organiza as operações. Domain: contém os modelos. Infra: concentra o acesso ao banco de dados com Dapper.
